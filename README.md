# 🧮 Calculator

A simple and user-friendly calculator built using **HTML, CSS, and JavaScript**. This project features a clean interface and basic calculator functionality.

## ✨ Features

* Simple and clean user interface
* Basic arithmetic operations
* Responsive and easy-to-use design
* Minimal JavaScript functionality

## 🛠️ Technologies Used

* **HTML5** – For structuring the calculator
* **CSS3** – For styling and layout
* **JavaScript** – For basic calculator functionality
